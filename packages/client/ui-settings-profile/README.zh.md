# `@deepseek-ai/dsh-client-ui-settings-profile`

[English](README.md) | 中文

DeepSeek Harness Desktop 仅限本机的“个人资料”设置与可选首次引导。非 loopback 浏览器不会收到 `profile` 设置页，也不会收到 `public-profile` 引导贡献。

引导步骤注册在 `-50`：位于产品欢迎说明 `-100` 之后、现有官方 DeepSeek 模型配置步骤 `0` 之前。它采用轻量三步流程：基本资料；工作方向与协作偏好；公开社交主页与逐字段 Agent 授权。每一步都允许不填；第一步和最后一步都提供“暂时跳过”；只有最后保存会用一次原子设置变更写入全部字段及持久完成标记。跳过只写标记。模型凭据仍由后续现有 DeepSeek 引导负责。

如果个人资料设置不可用、只读或读取失败，这一引导会仅在当前客户端会话中直接放行，不写入持久标记。这些状态下不渲染 `OnboardingSurface`，因此不会让应用根节点因无法保存的选择而变成 inert。Host 恢复可写后，之后的空白会话仍可再次尝试这个可选步骤。

独立设置页以 id `profile`、order `5` 注册，提供同一份完整可选表单。用户之后可以随时修改；把某项留空再保存即可清除该字段；“清空全部资料”需要确认并保留首次引导标记。每个授权复选框默认关闭，字段为空时不可开启。页面明确说明：开启后的字段会写入支持运行时上下文的本地 Agent 会话历史，导出会话也可能包含它们。关闭授权或清空资料只会阻止后续运行时快照，不会追溯删除已有会话记录。安全远程预设可能不使用这些个人资料上下文。

UI 接受 X 与 GitHub handle 或公开主页 URL，并在写入前规范为 handle；其他社交字段只接受文档规定的公开 HTTPS 主页格式。无效本地草稿不会发送到 Host 设置 API；Host schema 始终是权威校验边界。

UI 会持续提醒：资料字段只能填写公开信息，不能填写密码、API Key、Token、Cookie、私密邮箱或手机号。此包没有任何凭据字段，表单也不会调用或替代 Credentials API。

## 模型体验

### 本地个人资料配置

#### 模型看到的内容

模型不会直接看到此浏览器包的任何内容。引导、草稿、可见性复选框、保存状态、校验错误与清空确认都不会创建 Session 消息、提示词段、上下文条目或工具 schema。Host 的 `@deepseek-ai/dsh-user-profile` 包会独立把已持久化且逐项明确授权的字段投影到支持运行时上下文的组装中。一旦符合条件的本地 Agent 记录了这类快照，会话历史和导出文件就可能保留其中的已授权资料。之后关闭授权或清空字段只会停止后续投影，不会删除之前的会话记录。

#### Token 影响

直接影响为零。表单渲染与设置写入不会发起模型请求。之后符合条件的 Agent 步骤可能消耗 Host 所拥有、由 `@deepseek-ai/dsh-user-profile` 记录的授权资料上下文 Token。

#### KV Cache 影响

此包不会创建模型请求，因此不会创建或失效可复用前缀。资料保存发生变化后，Host 所拥有的运行时上下文后缀可能从下一次符合条件的 Agent 步骤起改变。

## 已知限制与暂缓事项

- **仅限桌面本机界面**：远程浏览器不能查看或编辑资料及其授权控制。
- **固定三步引导**：首版不会根据用户情况动态选择问题，也不会评估资料完成质量。
- **不支持头像上传**：个人图片与生成头像不在本切片中；UI 也不使用占位身份资产。
- **不保存凭据**：社交密码、Token、Cookie、私密联系方式与模型密钥都绝不能填在这里。
- **不保证进入远程 Agent**：`telegram-safe` 等安全预设可能抑制运行时上下文，从而忽略全部资料字段。
