# @deepseek-ai/dsh-channel

[English](README.md) | 中文

这是面向已认证文本渠道的供应商无关 Service Definition。传输插件注册 `ChannelProvider`，再通过 `ctx.channel.admit()` 提交标准化文本。唯一的产品消费者负责接纳、幂等与应用行为。出站文本通过 `ctx.channel.deliver()` 返回，并由消息指定的供应商发送。

传输插件必须在接纳前完成发送者认证与线协议校验。服务明确携带供应商、会话、发送者和外部消息四个标识，不暴露传输凭证或通用 RPC。`admit()` 只会在消费者完成持久接纳后结算，因此轮询供应商可在收到 `accepted` 或 `duplicate` 后推进外部 offset。

## 模型体验

### 已认证文本载体

#### 模型看到的内容

本包不会直接向模型提供内容。服务通过 `ctx.channel.admit()` 把标准化的已认证文本和不透明传输身份交给唯一注册的消费者，由消费者决定是否把文本加入 Agent 请求。

#### Token 影响

本包直接增加的 Token 为零。消费者可以按自身规则把已接纳文本加入模型请求；重复接纳和提供方投递不会在本包创建上下文。

#### KV Cache 影响

本包不创建模型请求，也不改变已有可复用前缀。会话选择和缓存行为由注册的消费者负责。

## 已知限制与后续工作

- 服务只承载文本。媒体、编辑、reaction、投递重试与供应商格式仍属于供应商或后续能力工作。
